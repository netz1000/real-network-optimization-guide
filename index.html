Windows Internet Optimization

How to Actually Speed Up Your Internet

Five things that genuinely make a difference — plus an honest look at what each one can and can't do. No magic registry hacks, no "download more RAM" energy. Just settings worth checking, in the order that matters.

⏱️ ~10 min read 🖥️ Windows 10 / 11 📋 Copy-paste commands ✅ Test after every step
⚠️

Read this first. None of the tweaks below will raise the speed cap of the plan you pay for. What they can do is remove bottlenecks, fix broken network states, and make sure your hardware is actually using the connection you already have.

Ground rules

  • Change one thing at a time. Then test. Then decide.
  • Keep what helps, revert what doesn't. Write down the original value before you change it.
  • Measure, don't guess. Run a speed test and a ping test before and after each change.
  • Hardware is the ceiling. If your router or PC port is gigabit, no software setting gets you to 2.5G.
🧪

How to test: run a speed test (download, upload, ping) and note the numbers. Then run ping 1.1.1.1 -n 20 in Command Prompt to check for packet loss and jitter. Compare results on the same server, at roughly the same time of day.

1

Go Wired (Ethernet) If You Can

This is the single biggest, most reliable improvement available to most people. A cable beats Wi-Fi on latency, stability and consistency — every time. It doesn't matter how good your Wi-Fi card is; air is a shared, noisy medium.

Which cable do you actually need?

Cat5e

1 Gbps up to 100 m

Perfectly fine for gigabit home internet. This is what most people need and already have.

Cat6

10 Gbps up to 55 m

Useful for multi-gigabit equipment over shorter runs. A solid default for new installs.

Cat6a

10 Gbps up to 100 m

The right pick for long 10-gigabit copper runs. Usually overkill for a home router.

🚫

Two things to stop believing:

1. Shielded cable is not automatically faster. UTP Cat5e is routinely used for gigabit Ethernet and works great. Shielding helps in specific electrically noisy environments — it is not a universal performance upgrade.

2. A cable bundled with other cables doesn't automatically slow you down. That's not how it works in a normal home setup.

✅

The real checklist: cable category, and your router port, and your PC's port all need to support the speed you're chasing. A Cat6a cable into a gigabit router is still a gigabit connection.

2

Fix Your Wi-Fi Positioning and Band

If you can't run a cable, this is where the real gains are. Two things matter more than any adapter setting: distance and frequency band.

5 GHz vs 2.4 GHz — pick based on where you are

Band Best for Trade-off
5 GHz Faster Being in the same room or one room away from the router. Higher throughput. Shorter range, struggles through walls and floors.
2.4 GHz Further Being far away, or with multiple walls between you and the router. Lower speeds and more interference from neighbours and appliances.
6 GHz Wi-Fi 6E / 7 Modern routers, clean spectrum, close range. Most limited range of the three. Needs compatible hardware on both ends.
  • Move closer. It sounds obvious, but it beats every software tweak on this page.
  • Elevate the router. Not on the floor, not inside a cabinet, not behind a TV.
  • Avoid thick walls and metal. Concrete, mirrors, fish tanks and radiators all eat signal.
  • Fewer obstacles = fewer retransmissions = lower latency.
3

Reset the Network Stack with CMD

⚠️

Be honest about what this is: these are troubleshooting commands, not a speed-boost script. They fix broken, misconfigured or stale network states. If your connection is already healthy, they won't make it faster.

How to run them

  1. Press Win and type cmd.
  2. Right-click Command Prompt → Run as administrator.
  3. Paste the commands below, one at a time or all at once.
  4. Restart your PC afterwards.
Command Prompt (Admin) 
netsh winsock reset
netsh int ip reset
ipconfig /release
ipconfig /renew
ipconfig /flushdns

What each one does

Command What it does
netsh winsock reset Resets the Winsock catalog — the layer apps use to talk to the network. Fixes issues caused by broken LSP entries (often from old VPN or firewall software).
netsh int ip reset Rewrites the TCP/IP stack registry settings back to defaults. Good for weird routing or IP configuration problems.
ipconfig /release Gives up your current DHCP lease. You will briefly lose connection.
ipconfig /renew Requests a fresh IP address from your router.
ipconfig /flushdns Clears the local DNS resolver cache. Useful after DNS changes or when sites resolve incorrectly.
🔌

Heads up: ipconfig /release temporarily disconnects you. If you're on a remote session, you'll drop it. Run these locally, not over RDP.

4

Network Adapter Settings (Device Manager)

Open it: press Win+X → Device Manager → expand Network adapters → right-click your adapter → Properties → Advanced tab.

🛑

Do not change every setting you see. There is no universal list — the options depend entirely on your hardware, driver and Windows version. Two people with different Wi-Fi cards will see completely different menus. Change only what's listed below.

📶 Wi-Fi adapter — the settings worth touching

Setting Recommended Why
Preferred Band Prefer 5 GHz Usually faster when you're near the router. If 6 GHz is available and your router supports it, prefer that instead — just remember its range is shorter.
Transmit Power Highest Maximises the adapter's transmit power in a typical home. A genuinely useful one.
Channel Width (2.4 / 5 / 6 GHz) Auto Let the adapter and access point negotiate. Forcing a width usually causes more problems than it solves.
Roaming Aggressiveness Medium A sensible default. Only adjust if you're moving between multiple access points and dropping connections.

These mirror Intel's own published recommended defaults for supported adapters: Auto channel widths, Medium roaming aggressiveness, Highest transmit power.

📶 Wi-Fi adapter — leave these alone

Setting Keep as Note
802.11a/b/g Wireless ModeDefaultDon't restrict compatibility with older networks.
802.11n/ac/ax/be Wireless ModeHighest supportedLeave enabled so modern standards can be used.
Throughput Booster / EnhancementDisabledIntel documents this as mainly affecting uploads and it can affect other clients sharing Wi-Fi airtime.
MIMO Power Save ModeAuto SMPSKeep the default. Test No SMPS only when troubleshooting low throughput.
Fat Channel IntolerantDisabledStandard default on Intel adapters.
Global BG Scan BlockingDefaultDon't disable background scanning without a specific reason.
U-APSD SupportDefaultPower-saving and AP compatibility behaviour.
Packet CoalescingDefaultA power-saving feature, not a speed booster.
ARP Offload / NS OffloadDefault (usually on)Handles network requests during sleep. No normal speed benefit from changing.
GTK Rekeying for WoWLANDefaultSecurity and wake behaviour.
Wake on Magic Packet / Pattern MatchDefaultWake-from-sleep functions — unrelated to internet speed.
Ad-hoc QoS Mode / Mixed Mode ProtectionDefaultLegacy or special-network compatibility settings.
Sleep on WoWLAN DisconnectDefaultSleep behaviour, not performance.
🔋

Power Management tab: if your Wi-Fi adapter repeatedly disconnects or dies after sleep, try unchecking “Allow the computer to turn off this device to save power.” This is a stability fix — not a speed improvement. Don't sell it as one.

🔌 Ethernet adapter — the settings worth checking

Setting Recommended When to change it
Speed & Duplex Auto Negotiation Check this first. Use Auto for normal gigabit and multi-gigabit links. Forcing a mode can cause negotiation failures or a slower link.
Receive Side Scaling (RSS) Enabled Distributes receive processing across CPU cores when supported. Keep it on.
IPv4 / IPv6 / TCP / UDP Checksum Offload Enabled (RX & TX) Hardware acceleration. Leave enabled.
Large Send Offload v2 (IPv4 / IPv6) Enabled Lets the adapter handle packet segmentation efficiently.

🔌 Ethernet adapter — leave at default

Setting Keep as Note
Interrupt Moderation / RateDefault / AdaptiveDisabling may reduce latency in some cases, but increases interrupt and CPU activity.
Receive Buffers / DescriptorsDefaultIncrease only if troubleshooting shows a receive-side throughput problem.
Transmit Buffers / DescriptorsDefaultIncrease only if transmit performance is a demonstrated problem.
Flow ControlDefaultDepends on the adapter and link partner — don't disable it as a universal tweak.
Adaptive Inter-Frame SpacingDefaultIntel states its default works best for most systems.
Jumbo Packet / Jumbo FrameDisabledEnable only when every relevant device on the network supports compatible frame sizes.
Energy Efficient Ethernet (EEE)DefaultTest disabling it only for link instability or unusual performance issues.
Green Ethernet / Ethernet Power SavingDefaultDiagnostic option if power-saving behaviour causes problems.
Gigabit Master/Slave ModeAuto / DefaultForcing a mode can cause negotiation failures.
Priority & VLAN / VLAN IDDefaultChange only if your network requires VLAN tagging or specific QoS behaviour.
Network Address / Locally Administered AddressBlankKeep the hardware MAC address unless you have a specific reason to override it.
ARP Offload / NS OffloadDefaultNot a routine speed optimisation.
Wake on LAN / Wake on Magic PacketDefaultDoesn't make an active connection faster.
🎯

The takeaway: on Wi-Fi, the only ones worth demonstrating are Preferred Band, Transmit Power and channel width. On Ethernet, check Speed & Duplex first. Everything else stays at default unless you're solving a specific problem.

5

Change Your DNS Resolver

DNS translates domain names into IP addresses. A faster resolver can make pages feel snappier because lookups complete sooner — but it does not increase sustained download speeds, and it doesn't reduce the latency of an already-established connection. Some providers also block malicious or adult domains.

💡

Pick one provider and use its matching pair. Don't mix a Cloudflare primary with a Google secondary — you'll get inconsistent filtering and routing behaviour.

How to set it

  1. Open Control Panel → Network and Internet → Network and Sharing Center.
  2. Click Change adapter settings on the left.
  3. Right-click your active adapter → Properties.
  4. Select Internet Protocol Version 4 (TCP/IPv4) → Properties.
  5. Choose Use the following DNS server addresses and enter your preferred / alternate pair.
  6. Click OK, then run ipconfig /flushdns in Command Prompt.

Resolver options

Provider / purpose Preferred DNS Alternate DNS
Cloudflare — general use 1.1.1.1 1.0.0.1
Cloudflare — malware filtering 1.1.1.2 1.0.0.2
Cloudflare — malware + adult content filtering 1.1.1.3 1.0.0.3
Google Public DNS 8.8.8.8 8.8.4.4
Quad9 — malicious-domain blocking 9.9.9.9 149.112.112.112
OpenDNS FamilyShield — family filtering 208.67.222.123 208.67.220.123
📉

The fastest resolver depends on your location and ISP. Treat these as options to test, not guaranteed upgrades. Try one, measure, try another, keep the best.

Things that sound like they work (but don't)

Clearing these up will save you more time than any tweak on this page.

"Shielded Ethernet cable = faster internet."

Nope. UTP Cat5e runs gigabit perfectly well. Shielding addresses electrical interference in specific environments, not speed.

"Running CMD network resets boosts your speed."

No. They repair broken network states. On a healthy connection they change nothing measurable.

"Custom DNS makes downloads faster."

Mostly no. DNS affects how quickly names resolve. Once you're connected to a server, your DNS provider is out of the picture.

"Enable every offload and tweak in Device Manager."

Risky. Most advanced settings are there for compatibility and power management. Changing them blindly causes instability, not speed.

"Jumbo Frames make everything faster."

Only in matching networks. If every device on the path isn't configured for the same frame size, you'll get fragmentation and worse performance.

"Cat6a will fix my slow connection."

Only if the cable was the bottleneck. If your router or PC port is gigabit, a 10G cable changes nothing.

✅ Quick recap checklist

  • Step 1 — Plug in Ethernet if you possibly can. Cat5e is enough for gigabit.
  • Step 2 — Get closer to the router. Use 5 GHz nearby, 2.4 GHz far away.
  • Step 3 — Run the five CMD reset commands as admin. Restart. Expect fixes, not speed boosts.
  • Step 4 — Device Manager → adapter → Advanced. Touch three Wi-Fi settings or one Ethernet setting. Leave the rest.
  • Step 5 — Try Cloudflare 1.1.1.1 / 1.0.0.1 or Google 8.8.8.8 / 8.8.4.4. Keep whichever tests best.
  • Always — Test after each change. Keep what helps. Revert what doesn't.
